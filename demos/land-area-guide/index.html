00

检查坐标系，先给源数据定义投影

从实际案例补充：注记明明在宗地面内，空间连接却全部 Join_Count = 0。

这次排错得到的经验：屏幕上看起来重合，不代表两个数据集具备正确且一致的空间参考。源注记没有坐标系时，应先核实其真实坐标系并运行“定义投影”，再测试空间关系；不要一味增大搜索半径。
定义投影：只补空间参考信息，不移动点或面Define Projection
仅示意数据的空间参考元信息变化，不代表“定义投影”会自动纠正偏移或转换坐标。

跟做顺序

1
逐一检查实际参与运算的源数据右键图层 → 属性 → 源 → 空间参考。分别检查宗地面、征收范围面、注记点；尤其留意 CAD 注记转换得到的点是否显示“未知（Unknown）”。不要只检查地图本身的坐标系。
2
核实原始数据真实使用的坐标系查看原始 CAD / 测绘成果的坐标系说明、已知控制点或可靠参照数据。不能只凭“图上差不多对得上”或者坐标值大小就认定具体投影带、中央经线和单位。
3
对空间参考未知的源数据运行「定义投影」地理处理搜索 Define Projection（定义投影）；输入数据选没有坐标系的源要素类，坐标系选经核实的真实坐标系。源注记和源宗地面若都未知，分别检查并处理；推荐先备份。输出处理会修改输入数据的空间参考信息。
4
验证后再进行空间连接检查图层源信息是否已显示正确坐标系、图层与已知位置是否吻合；用“按位置选择 → 相交”测试点与宗地面，再运行 Spatial Join，核对 Join_Count 与 TextString。

工具参数：定义投影（Define Projection）

参数 / 检查项如何设置
输入数据集实际参与空间连接且空间参考未知的源图层
坐标系已核实的真实坐标系，而不是猜测的地图显示坐标系
是否新建图层此工具直接修改输入数据的空间参考定义；先备份
处理完成检查源 → 空间参考，再测试“相交”
定义投影 · Define Projection补上正确“坐标说明”用于空间参考未知、但坐标值本身已经是正确值的源数据。坐标数值和几何形状不改变。
投影转换 · Project把数据变换到目标坐标系用于已知原坐标系、需要转换成另一坐标系的数据。会计算新坐标，并生成输出要素类。
源数据与目标面在地图上重合，为何仍可能无法关联？

ArcGIS Pro 地图可以按地图坐标系动态显示不同图层；但图层若缺少或错误标注空间参考，地理处理就缺少可靠的空间定位依据。另需检查是否选错同名图层、是否存在定义查询、点是否落在真正的目标面内。定义正确坐标系后应重新测试，不能保证所有 0 匹配都仅由这一问题造成。

勿混用：不知道真实坐标系时不要随意点选“CGCS2000”或某个投影带；若源数据的坐标已被实际变换，或当前坐标系已知但要统一到另一套坐标系，应使用“投影（Project）”，而不是靠“定义投影”修正坐标。
前置环节 · 先确定坐标身份，再做空间匹配下一步：确认图层与字段 →
01

确认图层与字段

先区分“用于统计的范围”和“需要统计面积的宗地”。

① 要统计的地块宗地面（紫色）一宗地对应一个面，记录宗地编号和地块面积。
在「交集制表」工具中选作“输入区域要素”。
② 用来划界的范围征收范围面（黄色）标出此次征收的空间范围。
在「交集制表」工具中选作“输入类要素”。

术语提示：实际工作中常把边界叫“宗地线、红线”；做面积计算时，选的是线围成的「宗地面」和「征收范围面」。

为什么要用“面”，不能直接用宗地线？

线用于表达边界，面才能表达占地范围并计算面积。在图层属性 → 源中查看“几何类型”：Polygon＝面，Polyline＝线。若手里只有闭合的边界线，先使用“要素转面（Feature To Polygon）”生成面，再继续操作。

看图先记住：紫色描边是「宗地边界」，黄色描边是「征收范围线」。虽然地图上看起来像线，实际参与面积统计的两个图层都应是 面要素 Polygon。单独的线要素需要先闭合并转为面。
字段含义后续用途
BH（示例字段名）每宗土地的唯一编号，如 A-01把统计面积准确找回原宗地
Shape_Area土地面几何面积TD_ZMJ 数据来源
TD_ZMJ土地总面积校验用
TD_HXN红线内面积交集制表 AREA 回填
TD_HXW红线外面积总面积 − 红线内

在宗地面属性表添加 TD_ZMJ、TD_HXN、TD_HXW 三个 Double（双精度）字段，用来存放总面积、征收范围内面积和范围外面积。征收范围面只负责划定边界。

运行地理处理前先检查：已完成第 00 步，所有参与分析的源图层空间参考明确且正确，面积采用适当的投影坐标系、水平单位为米；清除不需要的要素选择，确认没有意外定义查询；复制一份宗地图层再进行属性回填。
准备环节 · 不会改变原始几何下一步：注记赋编号 →
02

将独立注记编号赋给土地面

如果宗地面已经有正确的编号，可直接跳到第 03 步。

注记 → 面属性（空间关联示意）BH = A-25
注记 Feature To Point→Spatial Join（包含）→TextString → BH

独立注记图层有文字字段 TextString；可先运行“要素转点”，再以土地面为目标、注记点为连接要素进行空间连接。匹配字段不要误设成 TextString = YS，否则会额外要求两个字段值相等。

检查 Join_Count：0 = 未匹配；1 = 一个编号；大于 1 = 需要核查。如果点明明在面内却全部为 0，先返回第 00 步检查源注记与目标面的空间参考，确认目标图层选对，再测试“按位置选择 → 相交”；不要直接扩大搜索半径。不能只因为 BH 有值就认定编号关联无误，尤其要检查重复或异常的编号。
关键：BH 是标识，不是面积下一步：整理征收范围 →
03

先统一黄色征收范围

重叠范围不处理，后面可能把一块土地计算两次。

为什么要“融合 Dissolve”重叠处只保留一次

小提醒：融合的是同一征收项目的范围面，用于消除重叠面积；保留原始范围文件便于核对。

工具参数：融合（Dissolve）

参数填写
输入要素征收范围面
输出要素类征收范围面_融合
融合字段留空
统计字段留空
这个步骤只整理征收范围，不要将“征收范围”与“宗地”合成一个面。若你目前已经有无重叠的统一黄色范围，可以直接使用现有成果。
提示：始终保存原始征收范围面以便核对下一步：计算红线内面积 →
04

交集制表：得到每宗红线内面积

核心工具：Tabulate Intersection；输出的 AREA 已经是实际平方米数。

交集面积，不是整个宗地面积AREA = 面积（㎡）

工具参数：交集制表

参数选择
输入区域要素宗地面
区域字段BH（唯一且非空时）
输入类要素征收范围面_融合
输出表土地红线内面积统计
类字段 / 求和字段留空
输出单位SQUARE_METERS
AREA 和 PERCENTAGE 到底看哪个？

只想要实际平方米数，看 AREA；想看“这宗地有多大比例被征收”，看 PERCENTAGE。比如宗地总面积 100㎡，红线内 40㎡，则 AREA＝40㎡，PERCENTAGE＝40%。

编号（显示可能为“文本字符串”）AREA · 红线内㎡PERCENTAGE · %
A-0140.00000040.000000
A-0230.00000060.000000
A-0325.00000050.000000
读表要点：AREA 是红线内实际面积，PERCENTAGE 才是面积百分比。完全位于范围外的宗地可能不会出现在交集结果中。请保留宗地面全量记录，确认编号和空间位置无误后将其红线内面积记为 0。
BH 若重复或为空，不能作为每宗唯一标识。可新增长整型 TD_ID，计算 !OBJECTID! 后改用 TD_ID 统计与连接。
以上编号与面积均为教学演示数据下一步：把 AREA 写回土地 →
05

连接字段，计算红线外面积

以原始宗地面为完整成果，不能用交集结果替代宗地清单。

按 BH 匹配：表 → 土地面Join Field

工具参数：连接字段（Join Field）

参数选择
输入表宗地面
输入连接字段BH
连接表交集制表结果
连接表字段BH / 文本字符串（看实际字段名）
传输字段AREA

然后在土地面中计算三个 Double 字段。没有相交结果的宗地，在核实编号连接无误后，红线内记为 0。

TD_ZMJ = !Shape_Area!
TD_HXN = 0 if !AREA! is None else !AREA!
TD_HXW = !TD_ZMJ! - !TD_HXN!
Join Field 会更新输入表。若之前错误面积已经写入 AREA，重新计算后必须替换旧 AREA，重新计算 TD_HXN 和 TD_HXW；不能仅凭重新生成一张统计表就认为原土地数据已更新。
结果仍是一宗地一条记录下一步：统计剩余区域 →
06

征收范围扣除宗地，得到剩余面积

不是再做交集制表，而是“黄色征收范围 − 紫色宗地”。

擦除的方向不能反过来Pairwise Erase
范围内但没有碰到征收边界的宗地，会扣掉吗？

会。擦除看的是两个面的覆盖关系：完全在征收范围内的宗地全部扣除；跨界宗地只扣除范围内部分；完全在范围外的宗地不会扣除。

A
融合所有宗地工具：Dissolve；输入=宗地面；融合字段留空；输出=宗地面_融合。此处融合只用于扣除，不代替带 BH 的宗地原始数据。
B
成对擦除（Pairwise Erase）输入=征收范围面_融合；擦除=宗地面_融合；输出=征收范围内未覆盖部分。
C
统计输出面积在输出图层增加 GG_MJ（Double），通过“计算几何属性”以平方米计算；多个面要看 SUM 总和。

工具参数：成对擦除

参数填写
输入要素征收范围面_融合（黄色）
擦除要素宗地面_融合（紫色）
输出要素类征收范围内未覆盖部分
完全在征收范围外的宗地与黄色范围没有覆盖，不会扣减黄色面积；完全在征收范围内的紫色土地即使不碰黄色边界，也会全部扣除。
剩余图层先命名“未覆盖部分”或“未覆盖部分_待核实”。空间剩余不等于已确权公共土地。
以空间覆盖为准，不以土地 BH 分类为准下一步：排查异常面积 →
07

别让负数混入正式成果

用一宗虚拟地块演示：红线内面积接近总面积两倍时如何排错。

排错演示 · A-15
土地总面积 TD_ZMJ60.00000㎡
异常红线内 AREA118.000000㎡
异常红线外 TD_HXW−58.000000㎡
异常判据：同一宗地红线内面积不应大于该宗土地总面积。不能直接将负数改成 0，那会掩盖重叠统计或连接错误。
检查 1征收范围是否重叠同一位置是否被两个黄色范围面重复覆盖？先 Dissolve，再重跑交集制表。
检查 2BH 是否重复两个不同宗地若用了相同编号，用 BH 统计可能合并面积；改用唯一土地ID。
另外还要核查：宗地面自身重叠、意外选中记录、面积单位与坐标系、连接表重复键、旧 AREA 未更新。

按属性选择异常宗地

TD_HXN > TD_ZMJ + 0.001 OR TD_HXN < -0.001 OR TD_HXW < -0.001

此处 0.001㎡ 仅作数值舍入检查容差，不代表征收面积认定标准。修正空间数据后，重新交集制表、覆盖/更新连接面积，再重算两个内外字段。

先修数据，再出表下一步：成果验收 →
08

输出完整成果并验收

既能展示每宗面积，也能回答“范围内还剩多少未覆盖面积”。

应该保留的成果

成果图层 / 表说明
宗地面（含宗地编号）每宗 TD_ZMJ、TD_HXN、TD_HXW
征收范围面_融合统一的黄色征收范围
交集制表成果红线内相交面积依据表
宗地面_融合仅用于空间扣除
征收范围内未覆盖部分剩余区域空间成果及面积汇总
每宗：TD_ZMJ ≈ TD_HXN + TD_HXW
整体：征收范围面积 ≈ 宗地在红线内的几何覆盖面积 + 未覆盖部分面积
如各宗宗地本身相互重叠，“逐宗 TD_HXN 求和”可能超过土地几何覆盖面积；整体核算应采用融合后的宗地与范围的空间覆盖面积，重叠处只计一次。
核对方式范围总面积 = 宗地在范围内的覆盖面积 + 剩余面积按面叠加结果计算，重叠处只计一次；每宗地的内外面积分别核对。实际项目以完整征收范围为准。

从图形相交，到有依据的面积台账。

完整流程：核实坐标系并定义投影 → 查字段 → 注记赋号 → 范围去重 → 交集制表 → 属性回填 → 擦除剩余 → 异常核查 → 成果验收。可按步骤跟做，也可用于内部交流与教学分享。
