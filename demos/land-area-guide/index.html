从宗地编号、范围叠加到剩余区域统计：按图操作，获得可以按宗地核对的面积表。

宗地面征收范围面交集制表成对擦除
黄色：征收范围紫色：各宗地绿色：未被宗地覆盖的剩余区域
土地总面积宗地面自身的面积
红线内面积宗地与征收范围的重叠面积
红线外面积宗地总面积－红线内面积
叫法提示：地图上看着是“宗地线”和“范围线”，但参与面积分析的输入必须是封闭的 面要素（Polygon）。若只有线，先检查闭合并转面。后文统一称“宗地面”和“征收范围面”。
步骤 01

将独立注记编号关联到宗地面

如果 A-01、A-02 等文字与宗地面分属两个图层，面要素并不会自动具有编号字段。先让宗地面拿到自己的编号，再做面积统计。

工具设置
要素转点 Feature To Point输入：编号注记；输出：编号点；勾选“内部”
空间连接 Spatial Join目标：宗地面；连接：编号点；匹配选项：包含 CONTAINS
字段映射将注记中的 TextString（文本字符串）保留为宗地编号 BH
曾遇到的错误：“匹配字段”误填 TextString → 其他字段，会额外要求两个字段的内容相等，导致位置明明匹配却无法取得编号。只依靠位置关联时，匹配字段应留空。
输出属性表检查 Join_Count：1 表示匹配一个编号；0 表示未匹配；大于1需复核。注记点落在边界外时不要直接按最近距离批量覆盖。
步骤 02

先统一黄色征收范围

一处项目可能由多个范围面组成。如果两个范围面重叠，直接累计交集时就可能重复统计。先把同一项目的征收范围处理为一个不重复覆盖的整体。

融合（Dissolve）参数应填写
输入要素征收范围面
输出要素类征收范围_融合
融合字段留空（作为一个项目整体）
小提醒：如果正式征收范围尚未绘制完整，应先补全。面积统计以批准或核实后的范围为准，不能为了让结果好看而擅自扩张红线。
步骤 03

交集制表：得到每宗红线内的实际面积

工具名称：交集制表（Tabulate Intersection）。这一步统计“每块宗地进入黄色范围多少平方米”，不需要逐宗手工裁剪。

参数应选择
输入区域要素宗地面
区域字段BH（每宗唯一且非空时）；否则选自建唯一ID
输入类要素征收范围_融合
输出表宗地_红线内面积统计
类字段、求和字段留空
输出单位SQUARE_METERS（平方米）
结果字段意思
AREA红线内的实际面积，单位㎡
PERCENTAGE红线内面积 / 对应宗地总面积 × 100%
记住这一句：AREA 已经是实际平方米，不必用百分比反推。PERCENTAGE 才是占比。
为什么交集制表结果比原宗地少？

完全位于征收范围外的宗地可能不会出现在相交结果中；重复 BH 还可能将多块宗地作为同一区域汇总。最终必须以原始完整宗地面为主表，不能把交集结果直接当全部宗地清单。

步骤 04

连接字段，并算出红线外面积

先在宗地面创建三个 Double（双精度） 字段；若已有同名字段，无需重复新建。

字段中文别名如何取得
TD_ZMJ土地总面积原宗地面几何面积
TD_HXN红线内面积交集制表 AREA
TD_HXW红线外面积总面积－红线内面积

连接字段（Join Field）

参数填写
输入表 / 连接字段完整宗地面 / BH（或唯一ID）
连接表 / 连接表字段交集制表结果 / 对应 BH（或唯一ID）
传输字段AREA
“连接字段”会修改输入表，建议先复制一份宗地面用于正式成果。连接完成后核对 BH / ID 是否一对一匹配，避免重复编号回填总面积。

字段计算（Python 3）

土地总面积 TD_ZMJ：

!Shape_Area!

红线内面积 TD_HXN：

0 if !AREA! is None else !AREA!

红线外面积 TD_HXW：

!TD_ZMJ! - !TD_HXN!
空 AREA 只有在确认宗地确实不与征收范围相交后，才应按0处理。若是编号不一致或连接失败，先排查再计算。
步骤 05

扣除已调查宗地，得到范围内剩余面积

还需要统计黄色征收范围内，未被紫色宗地覆盖的道路、空地等部分。使用成对擦除（Pairwise Erase），直接获得剩余区域的面要素。

先融合宗地面设置
工具融合（Dissolve）
输入所有已调查宗地面
输出宗地面_融合（融合字段留空）
成对擦除参数设置
输入要素征收范围_融合（黄色）
擦除要素宗地面_融合（紫色）
输出要素类征收范围内_剩余区域

在剩余区域面添加 Double 字段 SY_MJ（剩余面积），计算 !Shape_Area!；若输出多个面，查看统计结果的 SUM。

容易混淆：完全位于征收范围内的宗地，即使不接触红线边界，也会被扣除；全部位于范围外的宗地不会扣除任何黄色面积。
空间上“未被已调查宗地覆盖”不等于法律权属上的“公共土地”。正式命名为公共、村集体等，应依据权属调查核实；在此之前建议叫“剩余区域（待核实）”。
步骤 06

别让负数进入正式成果

若 TD_HXW 为负数，代表计算的红线内面积超过原宗地总面积，应回头查空间数据和连接关系，不能直接改为0。

检查黄色范围两个范围面重叠时，先融合后重算。
检查 BH / ID重复编号、空编号是否导致统计合并？
检查原面有无重复几何、选中要素或定义查询？
0 ≤ 红线内面积 ≤ 土地总面积

在原宗地面使用“按属性选择”，找出面积异常的记录：

TD_HXN > TD_ZMJ + 0.001
OR TD_HXN < -0.001
OR TD_HXW < -0.001
正式统计前，还应确认输入要素使用同一适当投影坐标系、水平单位为米，计算单位统一为平方米。高程单位为米不等于平面单位一定为米。
步骤 07

输出完整成果并验收

保留的成果用途
宗地面_面积统计BH、土地总面积、红线内面积、红线外面积
征收范围_融合项目范围面积及统一空间边界
征收范围内_剩余区域未覆盖区域的几何与面积，后续核实权属
面积汇总表（Excel/CSV）核对、统计和汇报
两条面积守恒关系可用于检查成果；面积很小的差异可能来自几何修复、精度或计算口径，应记录容差并复核，不能无条件认为正确。
